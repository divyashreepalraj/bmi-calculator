# BMI Calculator

A responsive BMI Calculator web application designed to help users quickly calculate and understand their Body Mass Index (BMI) using standard BMI classification ranges.

The application provides a clean, accessible, and user-friendly interface with support for both Metric and Imperial measurement systems.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- BMI calculation based on height and weight
- Metric units support (cm, kg)
- Imperial units support (ft, in, lbs)
- BMI score display with visual classification indicator
- BMI categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obesity
- Visual BMI range scale
- Reset functionality
- BMI health information
- WHO adult BMI classification reference
- Clean and minimal Health & Wellness UI
- Accessible and easy-to-use form controls
- Privacy, Terms of Use, and Medical Disclaimer links

## 📱 Responsive Design

The interface is designed to provide a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile devices

The layout, typography, form fields, cards, buttons, and BMI range indicator adapt to different screen sizes.
